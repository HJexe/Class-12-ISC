# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

ISC Class 12 students looking for study material while preparing for classwork and board examinations.

## Product Purpose

Provide a free, organized hub where students can find and open notes, past papers, revision material, and other study resources by stream, subject, and topic.

## Positioning

The repository brings the existing ISC Class 12 resource collection together in one searchable directory with previews and direct Google Drive actions.

## Capabilities and Constraints

- Preserve existing resource content and current behavior, including stream and subject browsing, folder navigation, search, note previews, previous/next navigation, direct Drive open, download, share, reload, fullscreen, updates, routing, keyboard shortcuts, and mobile directory/viewer switching.
- This task changes the interface presentation only; it does not add or remove product features or make changes to study materials.
- Keep the site dark by default, matching the current experience. Do not add a white or light mode.
- Keep existing external resource destinations and current directory data intact.

## Brand Commitments

- Preserve the current product name and existing identity assets. No name, logo, or content rewrite was requested.

## Evidence on Hand

- The current resource directory and subject data in `index.html` and `notes-data.js`.
- Existing stream, note, viewer, notification, and sharing interactions in `index.html` and `notifications.js`.
- Current product description and feature list in `README.md`.

## Product Principles

- Make resource discovery quick and predictable.
- Keep access to study material free and direct.
- Preserve the existing breadth and organization of the resource collection.
- Keep the interface legible and usable on small screens.
- Use a calm, focused visual tone within the dark interface.
